# Security Policy

## Reporting a vulnerability
Please do not open a public issue.
Report it privately via GitHub: Security tab -> "Report a vulnerability".

## Supported versions
Only the latest version on `main` receives security fixes.

## Response and fix times
| Severity | Fix within |
|---|---|
| Critical | 7 days |
| High | 30 days |
| Moderate | 90 days |
| Low | best effort |
